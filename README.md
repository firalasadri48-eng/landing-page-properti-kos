# landing-page-properti-kos

Template landing page: properti kos.

Konten dummy Bahasa Indonesia (tanpa lorem ipsum). Ganti isi `content.json` dengan data asli sebelum dipakai produksi.

## Struktur
- `index.html` — halaman utama
- `content.json` — seluruh konten/teks/harga/kontak
- `site.css` / `site.js` — gaya & interaksi khusus site ini
- `shared/` — fondasi bersama (jangan diubah per site)
- `assets/` — gambar, font, ikon

## Coba lokal
Buka `index.html` langsung di browser, atau `python3 -m http.server` lalu buka http://localhost:8000.

## Deploy
GitHub Pages aktif dari branch `main` / root.
